# Panificadora Capri — Asa Norte, Brasília

Website institucional oficial e landing page de apresentação da **Panificadora Capri**, tradicional padaria, confeitaria fina, buffet e cafeteria localizada na Quadra 215 Norte em Brasília - DF.

Desenvolvido com estética premium em tons de **preto fosco, dourado acetinado e branco**.

## ✨ Funcionalidades

- **Design Premium:** Paleta preto e dourado com tipografia editorial elegante (*Cinzel*, *Playfair Display* e *Plus Jakarta Sans*).
- **Vitrine Real de Confeitaria:** Fotos autênticas da vitrine refrigerada com bolos confeitados, tortas finas, fatias recheadas e pudins artesanais.
- **Setores & Especialidades:** Apresentação da confeitaria, padaria de fornadas diárias, buffet matinal colonial e executivo de almoço, e salão de cafeteria.
- **Prova Social Integrada:** Avaliações reais de frequentadores da Asa Norte e notas verificadas do Google Maps.
- **Localização Interativa:** Mapa com coordenadas exatas, Plus Code, botões para traçar rotas com 1 clique no Google Maps e Waze, e cópia de endereço.
- **Módulo de Encomendas:** Formulário para solicitação de orçamento de bolos de aniversário, tábuas de frios e eventos via WhatsApp.

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/LucasAlexandreVasconcellos/Capri-Panificadora.git
cd Capri-Panificadora
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para gerar a build de produção:
```bash
npm run build
```
